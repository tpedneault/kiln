title = "One design document is the default export"
status = "accepted"
+++

The default export is the whole design as one document on one Confluence
page or in one file: one thing to read top to bottom, review and link to,
whose page history is the document's revision history. `sections` and
`tree` split the same document (EXPORT.md).
